# Dados GeoJSON

Esta pasta receberá as camadas vetoriais utilizadas pelo GeoEdu Portal UFMA.

Na próxima etapa, as feições demonstrativas serão substituídas por dados geoespaciais reais, preparados e validados no QGIS. Para publicação web, as camadas vetoriais deverão preferencialmente ser exportadas em EPSG:4326 (WGS 84), com nomes de campos claros e apenas os atributos necessários à atividade didática.
