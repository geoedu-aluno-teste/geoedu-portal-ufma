# Projetos de alunos — Geoprocessamento

Diretório destinado aos produtos vetoriais aprovados para integração acadêmica ao GeoEdu Portal UFMA.

Fluxo recomendado: QGIS → validação no Laboratório do GeoEdu → fork do repositório → inclusão do arquivo → Pull Request → revisão pelo Professor/GEOPRO.

Padrão sugerido de nomes: `GEO_AAAA_grupoNN_tema.geojson`.

Os GeoJSON destinados à visualização no portal devem ser exportados em EPSG:4326 (WGS 84), UTF-8, conter apenas atributos necessários e ser otimizados para uso WebGIS.
