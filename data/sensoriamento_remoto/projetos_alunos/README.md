# Projetos de alunos — Sensoriamento Remoto

Diretório destinado aos produtos acadêmicos compatíveis com publicação WebGIS no GeoEdu Portal UFMA.

Fluxo recomendado: processamento no QGIS/plataforma de sensoriamento remoto → preparação do produto Web → validação no GeoEdu quando GeoJSON → fork → inclusão do produto → Pull Request → revisão pelo Professor/GEOPRO.

Padrão sugerido de nomes: `SR_AAAA_grupoNN_tema.ext`.

GeoJSON vetoriais devem usar EPSG:4326 (WGS 84), UTF-8 e ser otimizados para WebGIS. Produtos raster terão fluxo próprio em versão posterior do portal; não devem ser enviados como arquivos raster pesados ao GitHub Pages sem preparação específica.
